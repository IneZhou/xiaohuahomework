# Testaccio 选址图片资料索引

本文件夹用于整理 Testaccio 初步选址阶段的公开图片资料。当前不直接下载和再发布图片原文件，原因是多数网页图片存在版权和使用条件限制；本资料库采用“图片链接 + 场地判断 + 图板用途 + 评价”的方式，便于后续手动核验、引用和重绘分析图。

## 文件夹结构

- `00_总览与区位/README.md`：Testaccio 区位、整体空间关系、底图与航拍线索。
- `01_Campo_Testaccio/README.md`：Campo Testaccio 旧球场遗址图片资料与评价。
- `02_Lungotevere_Emporium/README.md`：Lungotevere Testaccio 与 Emporium 河岸遗迹图片资料与评价。
- `03_Ex_Mattatoio_Campo_Boario/README.md`：Ex Mattatoio / Campo Boario 后工业空间图片资料与评价。
- `评价汇总.md`：三处地块基于图片资料的横向评价。

## 使用方式

1. 优先把图片作为“证据线索”，不要直接把网页图片放进最终图板。
2. 对适合图板使用的图片，后续应重新截图、重绘、拍摄或确认授权。
3. 每张图片都应对应一个设计判断，例如“围墙封闭”“硬化院落”“树荫河岸”“体育遗址荒置”。
4. 进入下一阶段前，应补充 Google Earth / OSM / Roma Capitale 官方地图截图，并统一标注比例、方向和来源。
