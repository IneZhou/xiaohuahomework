# 01 Campo Testaccio 图片资料与评价

## 资料 1：Campo Testaccio 现状荒置图

- 来源标题：La storia di Campo Testaccio dove è nata l'As Roma
- 来源链接：https://roma.fanpage.it/la-storia-di-campo-testaccio-dalla-nascita-dellas-roma-a-piu-di-10-anni-di-abbandono/
- 图片内容：场地内高草、荒置地面、残留灯杆和周边低矮建筑。
- 可用于：证明旧球场具备闲置/低效空间特征。
- 评价：
  - 优点：直接显示场地荒置状态，支持“社区体育遗址再激活”的选题。
  - 缺点：需要核实图片拍摄年份和当前状态，不能单独作为现状结论。
  - 设计启发：适合转化为“保留体育记忆 + 增加多代际活动 + 微气候改善”的社区公园。

## 资料 2：Campo Testaccio 历史航拍/球场图

- 来源标题：Campo Testaccio, 90 anni fa l'inaugurazione
- 来源链接：https://www.ilromanista.eu/romantica/partite/21476/campo-testaccio-90-anni-fa-linaugurazione-una-storia-tra-mito-popolare-e-abbandono
- 图片内容：历史时期球场看台、场地矩形边界和周边街区关系。
- 可用于：历史演变图、体育记忆图、场地形态复原。
- 评价：
  - 优点：能说明该地块不是普通空地，而是具有强社区和体育记忆的历史场所。
  - 缺点：图片偏历史叙事，无法说明当下公共性和生态条件。
  - 设计启发：可把原球场边界、看台记忆、入场路径转译成地面铺装、台地、环形步道或社区活动轴。

## 资料 3：Campo Testaccio 基础百科资料

- 来源标题：Campo Testaccio
- 来源链接：https://en.wikipedia.org/wiki/Campo_Testaccio
- 图片内容：旧球场位置和基本历史信息。
- 可用于：确认开放、关闭、拆除等时间线。
- 评价：
  - 优点：适合建立时间轴。
  - 缺点：图片和空间细节不足，需要结合街景、卫星影像继续核实。

## 图片评价结论

Campo Testaccio 的图片证据最强地指向“荒置体育遗址”和“社区记忆”。它适合做一个边界清晰、叙事明确的社区型景观项目，但生态、水文和城市尺度问题需要后续主动补充。若选择该地块，图片资料应重点服务于三类图纸：历史复原、现状荒置、社区再激活。
