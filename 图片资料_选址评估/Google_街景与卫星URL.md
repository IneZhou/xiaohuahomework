# Google 街景与卫星 URL 索引

本文件用于快速打开 Google Maps、卫星图和街景，辅助核实三个候选地块。坐标为初步定位点，仅用于快速跳转；最终图纸边界需要用 Google Maps / Google Earth / OSM 再次核准。

## 1. Campo Testaccio

### 搜索入口

- Google Maps 搜索：  
  https://www.google.com/maps/search/?api=1&query=Campo+Testaccio+Rome

- Google 图片/地图综合搜索建议关键词：  
  `Campo Testaccio Via Nicola Zabaglia Roma`

### 初步坐标入口

- 卫星图中心点：  
  https://www.google.com/maps/@41.8770,12.4755,18z/data=!3m1!1e3

- 街景入口：  
  https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=41.8770,12.4755

### 核验重点

- 场地是否仍有围挡。
- 原球场地面是否可见，还是已被重新平整或使用。
- 周边入口位于哪几条街。
- 与 Monte Testaccio、Ex Mattatoio 和居住街区的步行连接是否顺畅。

- 院落硬化比例、树冠覆盖、停车和临时活动空间分布。

## 5. 使用建议

1. 先用搜索入口确认地点名称，再用卫星坐标入口观察边界。
2. 街景入口可能跳到最近道路或可用全景点，不一定正好位于地块内部。
3. 对于 Ex Mattatoio 和 Campo Testaccio，优先看入口、围墙、地表材料和周边行人路径。
4. 对于 Lungotevere / Emporium，优先沿线移动街景，记录所有可下到河岸的入口和被道路阻隔的位置。
5. 最终图板不要直接截取 Google 图片作为无标注底图；应重绘或明确标注来源、日期和比例。
