# 02 Lungotevere Testaccio / Emporium 图片资料与评价

## 资料 1：Emporium 河港遗迹步道

- 来源标题：Emporium - Antico porto fluviale di Testaccio
- 来源链接：https://romaierioggi.it/emporium-antico-porto-fluviale-di-testaccio-8-foto/
- 图片内容：河岸步道、金属栏杆、砖拱遗迹、树荫和台地高差。
- 可用于：说明历史遗迹与现代河岸步道的并置关系。
- 评价：
  - 优点：能清楚呈现“遗迹 + 高差 + 栏杆 + 树荫 + 步道”的空间特征。
  - 缺点：图片局部性强，不能显示完整线性河岸和城市道路阻隔。
  - 设计启发：适合发展遗迹解说路径、树荫慢行、低干预展示平台。

## 资料 2：Turismo Roma 的 Emporium 图片

- 来源标题：Emporium - Antiguo puerto fluvial de Testaccio
- 来源链接：https://www.turismoroma.it/es/places/emporium-antiguo-puerto-fluvial-de-testaccio
- 图片内容：砖拱遗迹、树冠、栏杆和河岸下层空间。
- 可用于：作为相对权威的旅游/城市介绍图片，支撑遗迹价值判断。
- 评价：
  - 优点：来源更接近城市旅游官方介绍，适合引用为遗迹识别资料。
  - 缺点：偏景点介绍，缺少空间问题分析。
  - 设计启发：应把“遗迹可见”进一步转化为“遗迹可读、可达、可停留”。

## 资料 3：Lungotevere Testaccio 条目图片和说明

- 来源标题：Lungotevere Testaccio
- 来源链接：https://en.wikipedia.org/wiki/Lungotevere_Testaccio
- 图片内容：Lungotevere Testaccio 与 Emporium 相关河岸空间。
- 可用于：确认线性范围，即 Piazza dell'Emporio 至 Ponte Testaccio 一带。
- 评价：
  - 优点：帮助限定设计线性边界。
  - 缺点：不足以判断入口数量、断点和日常使用强度。

## 资料 4：Tiber 河岸节庆空间参考

- 来源标题：Lungo il Tevere Roma 2024
- 来源链接：https://www.romeing.it/it/lungo-il-tevere/
- 图片内容：Tiber 下层河岸步道、临时棚亭、夜间活动和桥梁背景。
- 可用于：参考 Tiber 河岸临时活动和夜间运营方式。
- 评价：
  - 优点：显示河岸空间在节庆期间可被激活，适合做运营场景参考。
  - 缺点：地点不一定严格位于 Lungotevere Testaccio，不能作为该地块现状证据。
  - 设计启发：可借鉴可拆卸设施、季节性活动和夜间照明，但必须结合防洪安全。

## 图片评价结论

Lungotevere / Emporium 的图片资料最能证明“历史河港遗迹被嵌入现代防洪和步行系统中”。它的优势是研究深度高、生态和水文议题自然成立；风险是图片多为局部遗迹或旅游视角，缺少完整线性系统证据。若选择该地块，下一步必须补充连续河岸截图、入口点位、道路断面和桥头空间照片。
