# 03 Ex Mattatoio / Campo Boario 图片资料与评价

## 资料 1：Mattatoio 主入口立面

- 来源标题：Mattatoio di Roma - Ex Macro Testaccio
- 来源链接：https://www.cosavederearoma.com/mattatoio-di-roma-ex-macro-testaccio/
- 图片内容：主入口三拱立面、铁门、石材门廊、牛形雕塑和前场铺装。
- 可用于：遗产入口、公共界面、历史身份表达。
- 评价：
  - 优点：入口识别度强，能说明屠宰场的工业遗产符号。
  - 缺点：偏建筑立面，不足以证明开放空间质量。
  - 设计启发：入口前场可作为公共性提升和遗产叙事起点。

## 资料 2：夜间入口和 Citta delle Arti 转型

- 来源标题：L'Ex Mattatoio a Roma diverra una Citta delle Arti
- 来源链接：https://www.artribune.com/uncategorized/2022/11/ex-mattatoio-roma-nuova-sede-accademia/
- 图片内容：夜间主入口、铺装广场、灯光和文化机构形象。
- 可用于：分析夜间使用、文化化转型和入口公共性。
- 评价：
  - 优点：显示场地已不只是废弃工业遗产，而是正在被文化教育功能重新定义。
  - 缺点：报道关注再开发，可能弱化日常居民使用问题。
  - 设计启发：设计应处理“文化活动人群”和“本地居民日常使用”的平衡。

## 资料 3：Mattatoio 院落空间

- 来源标题：A visit to Testaccio: what to see in one day
- 来源链接：https://www.italia.it/en/lazio/things-to-do/itinerary-testaccio-quarter-in-rome
- 图片内容：砖墙建筑、拱窗、碎石/石材院落、围栏和棚架。
- 可用于：判断院落硬化、线性围栏、低植被覆盖和工业空间氛围。
- 评价：
  - 优点：非常适合支持“硬化院落生态化”的设计议题。
  - 缺点：需确认图片具体位置和是否仍保持同样状态。
  - 设计启发：可发展雨水院落、树阵、可移动展览和保留工业构件的景观策略。

## 资料 4：Ex Mattatoio 改造平面图

- 来源标题：La rigenerazione dell'Ex-Mattatoio di Testaccio a Roma
- 来源链接：https://www.artribune.com/attualita/2024/05/citta-arti-roma-ex-mattatoio-testaccio/
- 图片内容：多个 Padiglione 的改造范围、建筑分布、院落和边界关系。
- 可用于：理解既有更新项目和设计不可触碰区域。
- 评价：
  - 优点：对判断设计范围非常重要，提醒不能把场地当作空白地块。
  - 缺点：是改造报道图，需回到官方规划或项目文件核实边界和建设时间。
  - 设计启发：景观方案应避开正在明确建设的建筑改造，聚焦公共开放空间、边界和连接系统。

## 资料 5：Monte Testaccio 与 Mattatoio 关系图

- 来源标题：The history of Testaccio district in Rome
- 来源链接：https://www.italyrometour.com/the-history-of-testaccio-district-in-rome/
- 图片内容：从 Monte Testaccio 视角看到周边建筑、绿化和历史地形。
- 可用于：解释 Monte Testaccio 与 Mattatoio 的空间和历史邻近关系。
- 评价：
  - 优点：帮助建立“陶片山-屠宰场-河港”三重历史叙事。
  - 缺点：旅游资料，精度和时间性有限。
  - 设计启发：可把 Monte Testaccio 作为视觉锚点和历史解释系统的一部分。

## 图片评价结论

Ex Mattatoio / Campo Boario 的图片资料最完整，既有入口、院落、改造平面，也有周边历史地形关系。它最适合作为研究型作品集主地块，但图片也证明了一个限制：这里已经存在明确的文化教育再开发趋势，设计不能假设完全自由改造。后续图板应把重点放在“开放空间系统、硬化院落生态化、遗产路径和公共性提升”。
